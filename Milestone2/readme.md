## Overview
This milestone implements a traffic sign detection and recognition system using the YOLOv8 object detection model as part of the Autonomous Driving project.

## Objectives
- Train a YOLOv8 model for traffic sign detection.
- Evaluate the model using standard object detection metrics.
- Perform inference on test images.
- Prepare the trained model for deployment.

## Tools Used

- Google Colab
- Ultralytics YOLOv8
